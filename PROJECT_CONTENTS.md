# Hasamex AI Case Study — Project Contents

This package contains the complete working project for the Hasamex AI Engineer case study.

## Original case-study transcripts included

- `backend/data/transcripts/Transcript_1_France.txt`
- `backend/data/transcripts/Transcript_2_Germany.txt`
- `backend/data/transcripts/Transcript_3_UK.txt`

These are the three transcript text files supplied for the assignment and are included unchanged in the project data directory.

## Main project areas

- `backend/` — FastAPI API, transcript parsing, retrieval, SQLite models, LLM providers, evidence validation, tests
- `frontend/` — React + Vite professional UI
- `docs/` — architecture, demo script, and project master plan
- `infra/` — Docker Compose setup
- `scripts/` — smoke test utilities
- `README.md` — setup and usage
- `TEST_REPORT.md` — validation and test results from the development environment
